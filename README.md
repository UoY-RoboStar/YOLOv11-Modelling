This is a repository to store RoboChart models to capture the small version of YOLOv11 (YOLOv11(s)) as described here - https://docs.ultralytics.com/models/yolo11/. The YOLOv11 network is modelled as a single ANN Controller using the new RoboChart metamodel. 


I am using the following paper as reference to create the model: YOLOv11: An Overview of the Key Architectural Enhancements, Rahima Khanam, Muhammad Hussain, https://arxiv.org/abs/2410.17725.


Parameters for the network structure (for the S version):

D - depth multiple = 0.50 <br>
W - width multiple = 0.50 <br>
MC - Max Channels = 1024
