Creating a RoboChart project to model YOLOv11 S as described in https://docs.ultralytics.com/models/yolo11/.

I am using this paper as reference to create the model: YOLOv11: An Overview of the Key Architectural Enhancements, Rahima Khanam, Muhammad Hussain, https://arxiv.org/abs/2410.17725.

The YOLOv11 network is modelled as a single ANN Controller in the new RoboChart metamodel. 

Parameters for the network structure (from S version):

D - depth multiple = 0.50 <br>
W - width multiple = 0.50 <br>
MC - Max Channels = 1024
